# NetProg

## Структура проекта

*   **daytime/** — реализация UDP-клиента сетевой службы Daytime (стандартный порт 13).
*   **echo/** — реализация TCP-сервера сетевой службы Echo (порт 7777, согласно сноске к заданию).

## Сборка

В каждой папке (daytime и echo) есть свой Makefile. Для сборки программы перейдите в нужную папку и выполните:

    make

## Запуск и тестирование

### Daytime (UDP клиент)

Запуск клиента с указанием IP-адреса сервера:

    cd daytime
    ./client 172.16.40.1


### Echo (TCP сервер)

Запуск сервера:

    cd echo
    ./server

Проверка работоспособности локально через утилиту nc:

    nc 127.0.0.1 7777
